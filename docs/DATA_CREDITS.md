# Data, libraries and attribution

- **Mapillary photographs**: https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data. Display contributor, capture date, source-image link and CC BY-SA 4.0 attribution on every street view, 2D capture and downloaded report. Preserve the applicable image licence when sharing analysed crops. A Mapillary account and registered app provide the browser client token.
- **pLitterStreet** (training data from v2 onwards): Sriram Reddy Mandhati, N. Lakmal Deshapriya, Chatura Lavanga Mendis, Kavinda Gunasekara, Frank Yrle, Angsana Chaksan and Sujit Sanjeev, *pLitterStreet: Street Level Plastic Litter Detection and Mapping*, 2024. Geoinformatics Center, Asian Institute of Technology. Dataset https://doi.org/10.5281/zenodo.8288500 (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/), paper https://arxiv.org/abs/2401.14719, code https://github.com/gicait/pLitter. Vehicle-camera street photos from Thailand, Vietnam and Sri Lanka, used to pre-train the detector before the Pune fine-tune. Credit the authors and the licence wherever the model or its images are shared; `training/prepare_plitter.py` writes a `credits.csv` for each prepared dataset.
- **TACO** (no longer used for training; the first baseline only): Pedro F. Proença and Pedro Simões, *TACO: Trash Annotations in Context for Litter Detection*, 2020. https://github.com/pedropro/TACO and https://arxiv.org/abs/2003.06975. Kept for the record because the v1 baseline in `docs/BASELINE_V1.md` was trained on it. That run found 0 of 54 litter items on the Pune test, so pLitterStreet replaces it. Retain each source photograph's licence if TACO images are ever shown again.
- **OpenStreetMap** contributors: https://www.openstreetmap.org/copyright. MapLibre's map attribution remains visible.
- **OpenFreeMap**: https://openfreemap.org/quick_start/.
- **Nominatim**: https://operations.osmfoundation.org/policies/nominatim/. User-submitted searches only, attribution, identifiable User-Agent, shared caching and at least 1.1 seconds between upstream request starts. No autocomplete or systematic geocoding.
- **MapillaryJS**: https://github.com/mapillary/mapillary-js, MIT.
- **shadcn/ui component pattern**: https://ui.shadcn.com and https://github.com/shadcn-ui/ui, MIT. Button variants and Radix-based dialog follow this pattern.
- **Ultralytics**: https://github.com/ultralytics/ultralytics and https://www.ultralytics.com/license. The proposed open college project uses the AGPL-3.0 option. Publish corresponding project source when sharing the trained application, and preserve upstream licence notices. Training code and model licensing remain relevant even though deployment uses ONNX Runtime.
- **ONNX Runtime**: https://github.com/microsoft/onnxruntime, MIT.

No Google Street View images are used. No synthetic test detections are included in the product. A model's confidence score is an internal score, not proof of a street's cleanliness.
